# Agent instructions

This vault is a personal knowledge system in Obsidian markdown. Cursor and Raycast are clients of these files. They are not a second database.

## Read first

Before changing the vault, read `10 Projects/Personal System/Project.md`.

## How to work

1. Stay inside the current item under Next in that project note. Do not start Later work in the same slice.
2. When a slice is finished, add a line under Done, move that item out of Next, and write the following slice under Next.
3. If a working decision changes, edit Working decisions and say why under Done.
4. One project, one folder. Design, plan, done, and left stay together.

## Where notes go

- `00 Inbox` — unsorted capture. Daily notes land here.
- `10 Projects` — work with an outcome. Open that folder's project note first.
- `20 Areas` — ongoing responsibilities. Learning is not built yet.
- `30 Resources` — reference you might study.
- `90 Archive` — finished or dropped.
- `Templates` — note templates. The daily template is `Templates/Daily.md`.

## Leave alone until the project note decides it

Do not add learning subjects, a project-management app, or a custom automation layer. Those choices are still open.
